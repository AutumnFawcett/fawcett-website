# Project Rules

- Use JavaScript only, not TypeScript.
- Use npm, not Yarn or pnpm.
- This project uses Next.js 16.2.7 with the App Router, React 19, and Firebase.
- Preserve the existing Firebase Authentication, Firestore, and Storage behavior.
- Do not modify or deploy Firebase Security Rules without explicit approval.
- Do not modify the `main` branch or deploy to production.
- Keep changes narrowly scoped to the requested task.
- Run `npm run lint` and `npm run build` after code changes.
- Report warnings separately from errors.
- Never commit environment-variable values, credentials, or private client data.
